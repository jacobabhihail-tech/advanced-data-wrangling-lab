## 🏠 Project 1 — House Price Prediction (Regression)

### 📌 Business Problem

Accurately estimating house prices is an important challenge in the real estate industry. Buyers, sellers, investors, banks, and real estate agencies all depend on reliable property valuations to make informed financial decisions.

The objective of this project is to build a regression model capable of predicting house prices using various structural and geographical features.
